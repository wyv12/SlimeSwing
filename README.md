# Slime Swing Games

Two small Unity arena prototypes built around a slime, grappling tendrils, and sentry turrets.

## Projects

- **SlimeSwingArena** — the fixed-screen five-arena version. It starts directly in play; destroy every turret to advance.
- **SlimeSwingJankBuild** — a separate, intentionally rough prototype with occasional control, rope, and turret-aim glitches. It remains playable and opens as its own Unity project.

Open either project folder in Unity Hub with Unity `6000.6.0f1`, then press Play in the default scene.
