# Slime Swing Games

Two Unity arena prototypes built around a slime, grappling tendrils, and sentry turrets.

## Projects

- **SlimeSwingArena** — fixed-screen, five-arena version. It starts directly in play; destroy every turret to advance.
- **SlimeSwingJankBuild** — a separate, intentionally rough version with occasional control, rope, and turret-aim glitches. It remains playable.

Open either project folder in Unity Hub with Unity `6000.6.0f1`, then press Play in the default scene. The optional Unity starter welcome preview and scene-template assets are omitted from this repository; the gameplay does not use them. Console-only passcode fields are blank in the repository copies.
